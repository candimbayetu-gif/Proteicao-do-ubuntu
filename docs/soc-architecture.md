# 🏛️ SOC Architecture Professional Framework

This document establishes the enterprise **Security Operations Center (SOC) Architecture** standards for aligning **Proteção do Ubuntu** with modern defensive operations (NIST / CIS benchmarks).

---

## 1. SOC Tiering & Operational Flow

```
[ Edge FortiGate / UFW ] ---> [ Server Telemetry (sec-telemetry / JSON) ]
                                          │
                                          ▼
                               [ SIEM / Log Aggregation ]
                                          │
                                     (Alerting)
                                          ▼
                              [ L1 / L2 SOC Analyst Triage ]
                                          │
                        ┌─────────────────┴─────────────────┐
                        ▼                                   ▼
            [ Automated Containment ]             [ Manual Incident Response ]
              (`sec-remediate`)                      (`sec-incident`)
```

---

## 2. Ingestion & Telemetry Alignment (`sec-telemetry`)
* **Standardized JSON Schema:** Every metric generated by `sec-telemetry` conforms to a rigid JSON structure containing timestamped system load, active sessions, UFW drop counts, failed authentication spikes, and active process inspection.
* **SIEM Forwarding:** JSON telemetry output (`/var/log/security-incidents/telemetry.json`) is designed for lightweight filebeat/fluentbit tailing into centralized SIEMs (Elasticsearch, Loki, Splunk).

---

## 3. Incident Triage & Response Playbooks

| Severity | Trigger Event | Automated Action (`sec-remediate`) | Analyst Action (`sec-incident`) |
| :--- | :--- | :--- | :--- |
| **P1 - Critical** | Unauthorized SUID modification / Recon tool detected (`LinPEAS`, `Nmap`) | Isolate network via UFW, terminate rogue processes | Generate forensic snapshot, preserve memory/logs |
| **P2 - High** | SSH brute-force spike (>20 failed attempts from single IP) | Fail2Ban temporary ban / IP block | Review auth logs for successful compromises |
| **P3 - Medium** | UFW firewall inbound drop spike | None (monitoring) | Review perimeter firewall rules |

---

## 4. Continuous Alignment Checklist
1. **Immutable Log Integrity:** Ensure logs ingested by `sec-monitor` and `sec-telemetry` are rotated and secured with strict permissions (`chmod 700`).
2. **Least Privilege Enforcement:** Run telemetry exporters under dedicated service accounts where applicable while maintaining read access to system logs (`adm` group).
3. **Automated Validation:** Run automated telemetry exports on cron/systemd timers to maintain real-time visibility without manual intervention.
